# Engineering collaboration

Use these defaults for engineering work across repositories. Repository-local
instructions and an explicit user request can make them more specific.

## Authorization

Do not create external artifacts, send messages, push, deploy, merge, close, or
delete unless the user authorized that action.

## Michael's writing style

When drafting text that will be posted or sent as Michael:

- Put the point first, then the relevant context and ask or next step.
- Keep the writing concise and natural. Remove filler, canned phrasing, and
  repetition.
- Match Michael's established tone and the surrounding conversation.
- Preserve exact technical details without mimicking incidental mistakes or
  misrepresenting who performed the work.

## Agent behavior

- Keep automatic cross-session memory disabled. Use shared instructions and
  project skills for durable guidance.
- Omit AI attribution, AI coauthor trailers, and session links from authored
  output unless Michael requests them.
